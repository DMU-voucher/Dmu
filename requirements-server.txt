# What the hosted copy needs. The office machine installs its own from run.bat,
# which adds Playwright and Chromium on top of these.
#
#   pip3.10 install --user -r requirements-server.txt
#
# Use the pip matching the Python version the Web tab is set to, not necessarily
# 3.10. That version is fixed when the web app is created and cannot be changed
# afterwards, and a mismatch serves 502-backend with an empty error log.
#
# No Playwright here on purpose: Chromium is 427 MB against a free account's
# 512 MB, so the server draws PDFs with WeasyPrint instead.
flask
segno
# Not just for check_pdf_engine.py: a print run is drawn a few pages at a time
# so no one request outlives the five minute limit, and this is what joins the
# pieces back into one sheet. Leave it out and every run goes back to being a
# single request.
pymupdf
weasyprint
