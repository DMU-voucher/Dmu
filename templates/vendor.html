Accepting DMU Food & Drink vouchers

De Montfort University issues these paper vouchers to attendees at university events. They are redeemable with you. This page explains what to do when one is handed over.

Scan this code once and bookmark the page it opens. It is the form where you record every voucher you take. The code is not on the vouchers themselves, so this sheet is the only place you will find it. Keep it by the till.

Any phone camera will do. Nothing to install, no password, no account. {% if cfg.qr_url %}

Then, when a customer hands you a voucher

  1. Check the voucher. The "valid until" date has not passed, the code in the red box is there and readable, and the value is the one printed in large type at the top.
  2. Open the form from your bookmark and enter the voucher code, for example {{ specimen.dmu_code }}. Please type it exactly as printed, including the dash and any leading zero.
  3. Serve the order up to the value shown on the voucher.
Keep the voucher. Do not hand it back. Holding on to the paper is the only thing that stops the same voucher being used a second time, so a voucher returned to a customer can be spent again and nothing will catch it.
If the order comes to less than the voucher value, no change or cash is given, and the difference is not carried over. If it comes to more, the customer pays the difference themselves as normal.
If you cannot get online, take the voucher anyway and write the code down. Nobody should be turned away over it.

Please do not accept

  • A voucher whose "valid until" date has passed.
  • A voucher whose code is missing or damaged. Without the code there is nothing to record, and the QR code is the same on every voucher so it does not say which one this is.
  • More than one voucher against a single transaction.
  • A photocopy, or a photograph of a voucher on a phone. The paper itself has to be handed over.

This is an example only. There is no QR code on a voucher: the only QR code is the one on this sheet. A real voucher carries its own code in the red box and a real date where this one says "{{ cfg.valid_until_label }} DD Month YYYY", and a real code never starts "00-". The value may differ from event to event, so always read the value printed on the voucher in front of you.
Questions on the day: contact the DMU event lead named on the booking, or DMU Venues at dmuvenues@dmu.ac.uk.
Quote the voucher code from the red box if you need to query a specific voucher with the university.
